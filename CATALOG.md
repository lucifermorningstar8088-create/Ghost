# Ghost Specialist Skills Catalog

**200 specialist skills across 25 domain packs.** Each skill has a unique ID and its own mission, trigger, inputs, outputs, workflow, quality gates, failure handling, specialist prompt, evaluation cases, and runtime integration note inside its domain pack.

> These are detailed instruction specifications. File presence does not prove runtime integration, passing tests, or production readiness.
