# Database migrations

Ghost uses Alembic to version PostgreSQL/Supabase-compatible schema changes.

From `apps/api`:

```bash
python -m pip install -r requirements.txt
# Render SQL without connecting to a database:
alembic upgrade head --sql
# Apply migrations to a database configured in the server environment:
alembic upgrade head
# Create a new revision after changing SQLAlchemy models:
alembic revision --autogenerate -m "describe schema change"
```

Set `DATABASE_URL` only in the backend environment. Never put database credentials in the web app or commit them to Git. Review autogenerated migrations before applying them.

The initial revision creates `channel_profiles` and its tenant/profile uniqueness constraint. It does not provision a database, enable authentication, or make the API production-ready. Back up production data before applying or downgrading migrations.
