# Ghost

Ghost is planned as an AI-powered social media growth and revenue operations platform for YouTube, Facebook, and Instagram.

## Skills library

This repository will contain 200 specialist skill modules for orchestration, research, channel audits, creative production, media production, publishing, analytics, AI/tool routing, quality assurance, security, platform integrations, monetization, rights/compliance, engineering, testing, UX, cost control, memory, operations, experimentation, governance, and audience intelligence.

Each module defines its mission, triggers, inputs, outputs, workflow, quality gates, failure handling, a reusable specialist prompt, evaluation cases, and runtime integration notes. A Markdown skill file is a specification, not proof of runtime integration or production readiness.

## Operating principles

- Evidence before claims; distinguish measured results from estimates.
- Account isolation, least privilege, secure secrets, platform terms, and user consent.
- Free-first resource policy; never silently trigger paid services.
- Independent quality gates, bounded retries, auditable changes, and human escalation for unresolved high-risk actions.
- No promises of virality, platform approval, or guaranteed revenue.

## Status

Skill modules and supporting infrastructure are being assembled. Runtime adapters, platform permissions, end-to-end tests, and benchmarks must be independently verified before production claims.
