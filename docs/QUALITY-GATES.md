# Ghost Quality Gates

## Non-negotiable blockers

- Unauthorized external action or account-scope mismatch
- Secret exposure, cross-account data leakage, or security control failure
- Unresolved material copyright or asset-rights concern
- Fabricated facts, citations, metrics, or tool-success claims
- Failed required tests or missing critical evidence
- Paid service use without explicit budget authorization

## Rubric

Score correctness, completeness, clarity, relevance, originality, reproducibility, accessibility, platform fit, cost fit, and risk handling from 0 to 5 with evidence. A high average never overrides a critical blocker.

## Release evidence

Record skill version, test fixture, expected/observed result, runtime versions, reviewer, date, failures, and remediation. Passing claims require recorded evidence.
